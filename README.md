# LaSirenaHMO

A modern, responsive web application built with Next.js and Supabase (Vercel anytime soon). This project features a scheduling and administrative dashboard for managing appointments.

## Tech Stack

- **Framework**: Next.js
- **Styling**: Tailwind CSS, Framer Motion
- **Database**: Supabase (PostgreSQL)
- **Forms & Validation**: React Hook Form, Zod


## Project Structure

- `/src/app`: Application routes and pages
- `/src/components`: Reusable UI components
- `/src/lib`: Utility functions and database wrappers
- `/supabase_migrations`: Database migrations and schema definitions
